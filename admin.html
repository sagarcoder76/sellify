Go live for free in 2 minutes

1. GitHub Pages (simplest)

Push this folder to a GitHub repo → Settings → Pages → Deploy from main branch. Your store is live at username.github.io/repo

git init && git add . && git commit -m "launch" && gh repo create sellify --public --source=. --push

2. Netlify (drag & drop)

Go to app.netlify.com → Add new site → Deploy manually → Drag the entire folder. Free SSL, CDN, and preview URLs.

No build needed — static files only. Works instantly.

3. Vercel / Cloudflare Pages

vercel.com or pages.cloudflare.com → Import project → Framework: Other → Build command empty → Output: /

npx vercel --prod (zero config)

All data is stored in localStorage, so your products persist per browser. For multi-device sync, export JSON and re-import, or connect a free backend like Supabase / Firebase (guide in README).
